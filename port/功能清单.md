# 这锅你来背 · 移植功能清单（验收表）

> 用途：Cocos 版逐项打勾。每项格式：**名称**：是什么 / 何时出现 / 关键数值或文案 / 原型出处。
> 出处行号以提交 `c2e6506` 为准；P0 加随机数种子后 `game.js`、`engine.js` 行号会漂移，以函数名为准。
> 文案用「」原样摘录；`{boss}` 表示玩家自定义的老板称呼，`{name}` 表示角色名，`{前三}` 表示按关卡名额变成「前三」/「前两名」（`rankWords()`，game.js:101）。
> 时长单位：s = 对局秒（暂停会停）；ms / 真实秒 = 真实时间（暂停不停）。两者在移植时不能混。

## 8. 核心机制与反馈（每局都有）

- [ ] **截止时间**：锅落到身上开始计时，甩来甩去不重置；各关期限 40/26/20/20/19s，急件 10s；到点在谁身上谁背锅 +1（急件 +3）；飞行中到点算甩它的人。game.js:57、74、781-793
- [ ] **爆炸背锅飘字**：主角「背锅 +N：{锅名}出事了」/「背锅 +3：急件炸了」（红，震 9/14，`blame` 音效）；同事「{name} 背锅 +N」（灰）。game.js:757-766
- [ ] **急件炸**：`boom` 音效（主角负责时音量 1，否则 0.5）；提示「急件炸在你手里，背锅 +3」或「急件炸在{name}手里，背锅 +3」2 真实秒。game.js:777-778
- [ ] **总账与排名**：总账 = 背锅次数 + 身上锅 × ½（急件按 3 口折）；排序：没压垮的在前 → 总账少 → 背锅少 → 甩出多；压垮的越晚压垮越靠前。game.js:1681-1687
- [ ] **星级**：第 1/2/3 名 = 3/2/1 星（周五前两名都是 3 星），名额外 0 星。game.js:1689
- [ ] **甩锅出手**：扔身上最急那口；自动瞄准扇形里「近且正前方」的人，锁定后在 1.25 倍扇形内不换人；按目标走位预判角度；锅速 620、追踪转向 6、射程 200（鸡血 250）、命中半径 40。game.js:39-42、501-579
