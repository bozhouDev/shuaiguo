## 已定的裁定（需求文档没写清的地方，按这里做）

1. **普通到点的 `src` 怎么取**：锅最后一次是被同事甩 / 反甩到你身上的（`receivePot` 的 `from` 是非玩家、非领导的同事）→ `mate`，`from` = 那个同事名；否则取 `pot.origin.src` / `origin.from`。急件到点一律 `p0`，小舅子身上的锅一律 `nephew`。
2. **`bell`**：铃响那一刻（`P9-1` 的 `bellTime()`）因清账炸掉的锅记 `src: 'bell'`，另带 `orig: { src, from }` = 按第 1 条算出的来源；来源短语按 `orig` 取。
3. **`Pot.origin`** = `{ src, from, t, id? }`，第一次落到人身上时写入，之后不改。撞领导一次派的 3 口共用一个 `id`（撞击序号），`t` = 撞上的时刻。
4. **「事件」聚合**：§6.2 里「`n ≥ 2` 的事件」和「撞上{from}那 3 口」，按 `bump` 的 `origin.id` 把同一次撞击派的锅合并成一个事件，`n` = 其中最终算到你头上的口数，`clock` = 撞上的时刻。`p0`、`protect` 本身单条 `n ≥ 2`，不用聚合。
5. **「如果少背 n 次会怎样」一律真算**：写一个纯函数（不改 `S`，调用前后状态逐字段相同，要有用例）——把玩家 `blames` 减 n 后按 `ranking()` 的同一套规则重排，返回假想名次和假想 `gap`。用于：
   - 差 1 副句「甩出去你就是第 {rank} 名」：假想名次 ≤ `passRank` 才写，`{rank}` 用假想名次；否则不写副句。
   - 差 2 到 3 副句 ①：假想能进线 → 「不然就过了」；否则 → 「不然就差 {假想 gap} 口」。**不用**需求文档里的 `gap − n + 1` 公式（它和排名规则对不上），报告里写明这处偏差。
   - 顶锅广告：n = 3 能进线才显示，并在 `calculateResult().ads.rescue` 里体现（不是只在画面层藏按钮）。
6. **打平副句**：`hisThrown == myThrown` 时不写副句（「手快的留下」不成立）。
7. **`rankTrail`**：下标 = `floor(workT())`，从 0 起每跨过一个整秒记一次；周一带教阶段不记；玩家压垮后停止。压垮副句取下标 `floor(crushedAt − t0 − 10)`，越界就不写。
8. **「全场最多」**：玩家 `thrown` ≥ 所有其他计入排名的人（不含不计排名的小舅子）即成立。
9. **文案生成放 core**：新建一个纯函数模块（例如 `core/verdict.ts`），输入 `calculateResult()` 的结果和对局状态，输出 `{ main, sub, color, retryLabel }`。画面层只负责摆放，方便在 node 里测文案。
10. **压垮主句**里的 12 用压垮口数常量，不写死。
11. **按钮次序（失败页）**：名次 → 主句 → 副句 → **重来**（黄色主按钮）→「带上 XX 重来」→ 排名表 → 复盘框 → 分享 / 顶锅 / 复活 → 返回首页。过关页保持现有次序，只把绿字主句换成 §6.4 的版本。旧的「和第 N 名总账打平，炸了的锅多」那句删掉。
12. **重来直接开局**只针对结算页的「重来」键：先确认现有 `startGame()` 是否已经跳过大厅和介绍页、`tutDone` 后是否不再走带教，已满足就不改。中央「{关名} · 再来一次」1 秒是**纯画面层**：这 1 秒内世界不推进（不调 core 的更新），之后正常开局，core 和录像不受影响。「带上 XX 重来」和暂停里的「重新开始」不加这 1 秒。
13. **上局就是他**：只在结算页按「重来」时，把上局 `lineInfo` 对应的那个同事（排名失败、非压垮、不是小舅子）的 `key` 和名字放进 `startGame` 的参数，不存档；新局按 `key` 找人（找不到按名字，再找不到就不显示），在 1 秒提示结束、正式上班起挂 3 秒。颜色用红 `#E8504A`（对你不利）。画法沿用 P7-6 常驻节点，不每帧重画。
14. 顶锅按钮文案「顶锅 -3，刚好够」，减号和现有按钮一样用 ASCII `-`。

拿不准的其他细节：选最保守的做法，写进报告「待裁定」。

- 每条 `src` 路径至少一个用例：造场景让锅落到玩家身上到点，断言 `blameLog` 最后一条的 `src` / `from` / `n` / `clock`。同事甩来的天降锅记 `mate`；清账炸的记 `bell` 且 `orig` 正确；撞领导 3 口共用一个 `id`。
