# P7-6 · 对局画法重构：从"每帧全部重画"改成常驻节点

先读：`AGENTS.md`、`DESIGN.md`、`port/tmp/p7-3/report.md`、`port/tmp/p7-4/report.md`、`port/tmp/p7-5/report.md`（性能上报口径）、`implementation-notes.md` 顶部、`cocos/assets/scripts/view/` 下的 `DrawSurface.ts`、`WorldPainter.ts`、`WorldView.ts`、`WorldAssets.ts`、`InputView.ts`、`HudView.ts`、`MatchUi.ts`、`PerfProbe.ts`，以及原型 `js/game.js` 的 draw 部分（视觉标准）。

## 为什么要做

- 这个游戏不复杂，但 iPhone 17 Pro 和小米 17 Pro 玩第 5 关都会卡，还会发烫。
- 根因是移植时的画法：`DrawSurface` 模拟网页 Canvas，每帧把所有人、锅、名牌、影子、视野、提示从头再画一遍。结果是第 5 关每帧约 150 次 draw call，后期 170 次以上，还有几十个 Graphics 和 50 个 Label。正常的 Cocos 游戏不这样画。
- 泊舟定的原则：**目标是做一个好游戏，不能为了性能把画面或体验变差。**降分辨率、降帧率不是解决办法，只能当调试开关。**需要新素材可以重新生成**（Codex image_gen，按 `AGENTS.md` 的出图流程）。

## 目标

- 对局画面改用常驻节点（retained mode）：每个人物、锅、名牌、领导、头顶标记、边缘提示各自是长期存在的节点，创建一次，每帧只改位置、朝向、帧、透明度、显隐。不再每帧 begin / 重画 / 隐藏多余。
- 按目标值验收：第 5 关开局和后期（119 秒前后，三十多口锅）：
  - draw call 降到原来的三分之一以下（参考：≤ 50）。
  - 每帧脚本耗时（逻辑 + 绘制）降一半以上。
  - 每帧新建 Graphics 网格接近 0。
  - 满分辨率（不封顶 DPR）。
  - 写出实测值，达不到的写清楚原因。

## 做法要点（你可以改进，但要说明理由）

1. **合批优先**：所有对局里的像素图都在一张（或少数几张）图集里，同层同材质连续提交。层级按原型的遮挡关系固定下来：地面 → 锅尾光圈/烟 → 影子 → 按 Y 排序的人物（含人物身上的锅、头顶标记）→ 视野 → 飞锅、爆炸 → 名牌、飘字 → 边缘提示 → HUD。
   - 按 Y 排序只需要调整人物容器的子节点顺序；人物自身的部件放在人物容器里。
   - 遮挡关系必须和原型一致，有交错的地方逐条列出你的处理方式。
2. **形状换成图**：影子、锅尾危险光圈、视野扇形、倒计时圈、边缘箭头底圈这类形状，优先换成图片（9 宫格、可拉伸、`FILLED` 径向填充）。
   - 原型里是矢量形状的，可以生成像素风的新素材替代，但观感要和原型一致或更好，并给出对比图。
   - 视野扇形如果角度或半径会变，评估用固定贴图加缩放 / 旋转 / 填充是否够用。
3. **文字**：名牌、头顶数字、飘字是高频文字。
   - P7-4 试过 `CacheMode.CHAR`，导致描边和字形明显变了，所以被否决。
   - 可以考虑 BMFont 位图字（用现有字体生成，覆盖游戏里实际用到的字），或者文字不变就不重排。
   - 目标是文字也能合批，而且字形、描边要和现在一致。生成字体的脚本要放进 `cocos/tools/`。
4. **HUD 和摇杆 / 甩键**：同样改成常驻节点，只在数值变化时更新。
5. **DrawSurface 保留**给大厅、结算、介绍等外围界面使用（这些界面已经降到静止时 15 帧）。本轮只重构对局世界层、对局 HUD 和操作区。

## 验收

- 玩法一帧不变：黄金录像（源码 + `test:golden:compiled`）100/100。新的画面层只读 core 状态，不回写（`frameAim` 除外，沿用现有约定）。
- 画面和原来一致：第 1 / 3 / 5 关固定种子定格，加第 5 关 100 秒、119 秒，新旧逐张并排对比。
  - 因为改成贴图，不要求逐像素 0 差，但每张都要给差异热图，逐条说明差在哪里、为什么可以接受。
  - 人物、锅、文字、颜色、遮挡顺序不允许有可见变化。新素材替换的形状要和原来一样清晰或更清晰。
- 性能：用 `perf-bench.mjs` 给出第 1 / 5 关 10 秒、100 秒、119 秒的前后对比表。
- 动效不丢：震屏、甩键放大、锅爆炸、急件锅放大、光圈呼吸、表扬贴纸、飘字、领导视野、被压垮、复活 / 顶包、带教遮罩和手指，逐项列出检查结果。
- 门槛：core、wechat、cloud、check:types、保护检查、`.meta`、check-spread、perf / tour / result-view 全过。
- 新素材：洋红底，不放文字，符合 DESIGN.md 色板，像素比例一致，体积记入报告。

## 不许做的

- 不运行 CocosCreator，不构建，不提交，不推送。不改原型，不改玩法和数值。
- 不降渲染分辨率，不降对局帧率。
- 新建 `cocos/assets` 文件时，一次性带好 `.meta`（importer 写对、UUID 唯一），报告第一行写"需要刷新编辑器 + 构建"。
