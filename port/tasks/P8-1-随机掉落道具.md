# P8-1 · 随机掉落道具：清锅、无敌、延时

先读：`AGENTS.md`、`DESIGN.md`、`这锅你来背-核心玩法.md` 的「随机掉落道具」一节（本卡的规则来源，以它为准）和「画饼大会」一节、`implementation-notes.md` 顶部、`.claude/rules/gameplay-code.md`、`.claude/rules/test-standards.md`，以及 `cocos/assets/scripts/core/` 下的 `schedule.ts`（饼的生成和拾取，本卡照着它做）、`state.ts`、`pots.ts`、`leaders.ts`、`agents.ts`、`config.ts`、`levels.ts`、`random.ts`、`simulate.ts`，`cocos/assets/scripts/view/` 下饼和鸡血状态的画法，`cocos/tools/pack-match-atlas.py`。

## 为什么要做

- 以后要接激励视频广告，换「看广告领道具」。流量主还没开通，先做成局内随机掉落，让玩家先尝到甜头；道具效果以后不改，只多一个来源。
- 这是移植后第一个**新玩法**，不是翻译原型。原型 `js/` 不动。

## 规则（泊舟 2026-11-04 定，数值先这样，以后会调）

- **只有玩家能捡**：同事和领导走过去不捡，AI 也不追道具（自动模式下的玩家 AI 例外，见「平衡模拟」）。
- **捡到立刻生效**，不加按钮。
- **掉落时间**：每局第 25、60、95 秒左右各一个（可以有 ±3 秒抖动）。落地前 1 秒光柱预告，地上停 12 秒，最后 3 秒闪烁，没人捡就消失。关卡结束前不够 12 秒的不刷。
- **刷新点**：在地图上预设 6～10 个点，都在老板巡逻路线边上、会议室门口这类有风险的位置；不能在墙里、桌子里，玩家要走得到。点位写进关卡数据（各关共用一张图，可以共用一组点）。
- **哪一种**：清锅 20%、无敌 40%、延时 40%。
- **周一**：带教阶段不刷，带教结束后按正式上班的时间轴刷（时间点按正式上班开始算，换算方式写进报告）。其他关都刷。
- **效果**：
  - 清锅：身上的锅全部消失，不算背锅、不算甩出；正朝你飞的锅不算在内。
  - 无敌：5 秒内天降锅、领导丢的锅、同事甩来的锅、撞到领导都不生效（砸不中 / 不加锅）。你照常能甩、能反甩；在领导视野里甩照样被抓。无敌中再捡到无敌，时间刷新为 5 秒，不叠加。
  - 延时：身上每口锅的截止时间 +15 秒，急件也一样。
- **证书**：捡道具不影响「凭本事下班证书」。

## 做法要点（可以改进，但要说明理由）

1. **玩法在 core，画面在 view**：道具状态（地上的道具、玩家无敌到期时间）放进 core 状态，view 只读。数值放 `config.ts` 常量或关卡数据，不在逻辑里写死。
2. **随机数要隔离**：道具的时间抖动、刷新点、种类用**单独的随机流**（按对局种子派生），不能消耗原来的 `E.rand`，否则原有对局全部改变。
3. **开关**：关卡或对局参数里加一个总开关（如 `itemDrops`）。黄金录像、`test:golden:compiled`、现有 core 测试里的统计**默认关掉道具**，结果必须和改动前完全一致。正式对局默认打开。
4. **画面**：
   - 素材源图：`assets_pixel/sheets/s_items_p8.png`（泊舟给的，三个蓝底按钮：扫把 = 清锅、盾牌 = 无敌、秒表 = 延时，黑色背景）。切成 3 张，**保留蓝色底框**（在地图上像道具箱，显眼），缩到和地上的饼差不多大小，转成和现有像素图一致的比例，打进对局图集。
   - 光柱预告、最后 3 秒闪烁、捡到时的飘字（「清空！」「无敌 5 秒」「+15 秒」）、无敌时主角身上一圈金光 + 头顶剩余秒数、清锅时锅一口口弹飞、延时时锅上倒计时数字往上跳。颜色按 DESIGN.md §3：对你有利 = 绿；金光沿用黄 / 金。
   - 能复用的特效（鸡血光、飘字、爆炸）先复用。沿用 P7-6 的常驻节点画法，不要退回每帧重画。
   - 音效复用现有的（如 `buff`、`revive`），写清用了哪个。
5. **第一次捡到**时给一条底部提示，说明这个道具干什么（每种一局最多一次）。
6. **结算统计**：记录本局捡到几个、各是什么、几个过期没捡。如果现有埋点 / 性能上报管线能顺带记一个 `item_pick` 事件就加上；改动大就写进「发现但未改」。

## 平衡模拟

- 自动模式（`?auto=1` / `simulate`）下的玩家 AI 加一个简单策略：道具在一定距离内、且不用穿过领导视野就去捡。只影响玩家 AI，不影响同事。
- 第 1～5 关各跑 100 局以上（不复活）：道具关 vs 道具开的过关率、压垮率、平均背锅，列成表。第 5 关的目标是过关率约 3%～8%（现在 8%），如果开了道具明显超出，写出建议调低的掉落频率或数值，**不要自己改**，交给泊舟定。
