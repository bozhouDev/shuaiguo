# P6-2 · 大厅好友排行榜（含开放数据域）

先读：`AGENTS.md`、`DESIGN.md`（§3 色板、§7 界面、§8 文案）、`implementation-notes.md` 顶部（P6-1、P5-1 和之后的修复）、`port/tmp/mockups/排行榜对比稿.html`（方案 B）、`cocos/assets/scripts/view/AppView.ts`、`LobbyView.ts`、`UiPaint.ts`、`ScreenPaint.ts`、`platform/CloudServices.ts`（好友 KVData 写入：键 `sg_debt_v1_<关卡ID>`，值 `{"v":1,"debt":数字}`）、`platform/Platform.ts`。微信开放数据域文档自行查阅（`wx.getFriendCloudStorage`、`wx.getUserCloudStorage`、`getSharedCanvas`、`postMessage`、Cocos 3.8 `SubContextView`）。

## 泊舟已定

- **排行榜放大厅里，单独一页**，样子按对比稿方案 B。
- **只做好友榜，不做全服榜**：去掉对比稿里的"好友 / 全服"标签。客户端已关闭全服上传，云函数保留，不要动。
- **按关分开排**：顶部切换周一到周五，比的是该关最好"总账"（越少越好，相同的按原型比较规则，没有就按昵称稳定排序）。只列打过有星的好友。

## 要做的

1. **大厅入口**：加一个"排行"入口，用 `ui_crown` 图标。放在哪由你按现有大厅布局定（例如底部"老板名称 / 玩法"那一排），要求 375×812、375×667、360×780 三种屏幕都不挤、不压别的元素，和现有按钮同一套样式。网页版也有入口。
2. **排行页（主域，Cocos 画）**：顶部深蓝面板（皇冠 + "谁背锅最少" + 关闭），周一到周五五个关卡标签（默认选大厅当前选中的关；未解锁的关也能看），中间列表区，底部"去上班"（直接进当前选中关的介绍页）。颜色、描边、硬阴影、字体和现有界面一致。文案短而损，符合 `DESIGN.md` §8。
3. **列表区（开放数据域画）**：
   - 自定义开放数据域代码放到 `cocos/build-templates/wechatgame/openDataContext/`，保证每次构建都覆盖 Cocos 默认生成的模板（先验证 Cocos 3.8.8 构建时 build-templates 是否会覆盖它生成的 openDataContext，不会就找可行做法并写清楚）。
   - 用原生 canvas 2D 直接画，不必沿用默认的 minigame-canvas-engine 模板；只画列表行：名次、头像（`wx.createImage`，加载失败用纯色方块）、昵称（系统字体，超长截断加"…"）、总账。自己那一行用便利贴黄底高亮。
   - 前三名名次用金 / 银 / 铜色；空列表时显示一句文案（比如"还没有同事打过这一关"）。
   - 主域通过 `postMessage` 告诉它：当前关卡、视口大小、滚动位置、显示 / 隐藏。数据按关缓存，切关不重复拉；列表超出时能上下滑动（主域转发触摸位移）。
   - 用 Cocos `SubContextView` 把共享画布显示在列表区；离开排行页时停止刷新，避免一直占性能。
4. **网页版**：没有开放数据域，列表区显示"好友排行只能在微信里看"，其他照常。
5. **隐私**：`wx.getFriendCloudStorage` 需要在小程序后台的《用户隐私保护指引》里声明"朋友关系"。代码里处理好拒绝 / 失败（显示文案，不报错），并在报告里写清泊舟要去后台填什么。
